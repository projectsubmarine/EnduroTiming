## 1. クラス設定・ライダー登録（① ライダー登録タブ）
### 1-1. 参加クラスを登録する
- 「参加クラス設定」で、その大会の参加クラス（例：IA、IB、ビギナー…）を1つずつ追加する。
- 登録したクラスの並び順が、結果表・スタートリストの表示順にもなる。▲▼で並べ替え、「名称変更」でクラス名の変更ができる（登録済みライダーのクラスも自動で追従する）。
- 「BIB先頭の数字」（1〜9、任意）を設定すると、BIBナンバーの100の位でそのクラスを識別できるようになる（例：IA＝1→101〜199番、IB＝2→201〜299番。下2桁00の番号は欠番のため使わない）。1つの数字は1クラスのみに割り当てられる。あとから「先頭の数字」ボタンで変更・解除もできる。
- ライダーが使用中のクラスは削除できない（先にライダー側のクラスを変更してから削除する）。

### 1-2. ライダーを登録する
- BIBナンバー・氏名は必須。読み仮名・参加クラス・ICタグID・特記事項は任意。
- **BIBナンバーは3桁（100〜999）。下2桁が00の番号（100, 200, …, 900）は欠番のため使用できない。** 参加クラスに「BIB先頭の数字」が設定されている場合、入力したBIBがその番号帯と一致しないと登録できない。
- 参加クラスを選ぶと、そのクラスの番号帯の中で未使用の最小番号がBIB欄に自動入力される（空欄の時のみ。手で書き換えることもできる）。登録後もクラスは保持されるので、同じクラスのライダーを続けて登録すると番号が自動で繰り上がる。
- ICタグIDは今後のRFID等による計測簡略化のための拡張項目（現時点では手入力・重複チェックのみ）。
- Enterキーで次の入力欄に移動し、最後の欄でEnterを押すと登録される。
- 同じBIBは重複登録できない。BIBを変更しても記録（タイム）は外れない（内部IDで紐づけているため）。

### 1-3. エントリーリストをCSVから取り込む
- 申込システムなどから出力した、氏名・読み仮名が入ったCSVファイルがあれば、1件ずつ入力する代わりに「CSVから取り込む」で一括登録できる。
- ファイルを選ぶと、列の対応付け画面が開く。各列の見出し（プルダウン）で「氏名」「読み仮名」「特記事項」「使用しない」を選ぶ（見出し行の文言から自動で推測されるが、必ず確認する）。先頭行が項目名の場合は「先頭行はヘッダー行」のチェックを入れたままにする。
- 「氏名」が空の行は取り込まれない（取り込み後に件数とスキップ件数が表示される）。
- 取り込んだ直後は **BIBナンバー・参加クラスが未設定** になる。①の一覧に「未設定」と表示されるので、1件ずつ「編集」から設定する（1-2と同じ手順）。
- 同じ人を2回取り込むと2行になる（重複チェックはしない）。間違えたら一覧から「削除」する。
- 文字が崩れて表示される場合は、ファイルの文字コード（Shift_JISなど）を確認する。基本的にはUTF-8・Shift_JISのどちらでも自動で判別する。

## 2. スタートリストの作成・出走（② スタートリストタブ）
- 画面上部の「クラスの出走順」で、どのクラスから出走するかを▲▼で設定・変更する（①の「参加クラス設定」の表示順とは別管理）。各クラスの中は自動でBIBナンバーの小さい順になる。
- 下の出走リストは、クラスの出走順→BIBの順で自動的に並ぶ。「並び順を初期化」ボタンでいつでもこの順番に戻せる。
- 下の一覧の▲▼ボタンで、個々のライダーの出走順を手動で入れ替えることもできる。
- ライダーを登録・削除すると、一覧の末尾に自動で追加／除外される（並び替えた順序はできるだけ保たれる）。
- 「印刷・PDF保存」で、スタッフが現場で使う紙の出走リストを作成できる。

## 3. タイム入力（計測・都度のリザルト入力）（③ タイム入力タブ）
- BIB、セクション番号、スタート時刻、ゴール時刻、状態（完走／DNF／DNS／DSQ）を入力する。
- スタートとゴールは別々に入力してもよい（先にスタートだけ記録 → 後でゴールを追記、が可能）。同じBIB・セクションに再入力した場合、空欄の項目は既存の値を残す。
- 時刻の入力形式：`10:05:23.45` のような区切り付き、または `100523.45` のような詰め入力のどちらでも可（全角数字も可）。

## 4. 結果確認・印刷（④ 結果・順位タブ）
- 総合順位／クラス別順位を切り替えて確認できる。入力済みの記録はリアルタイムに反映される（都度のリザルト入力）。
- 「印刷・PDF保存」でその場で成績表を印刷・PDF化できる。「結果をCSVで保存」でCSV出力もできる。
- 順位ルール：①完走セクション数が多い順 → ②合計タイムが短い順。DSQを含むライダーは順位なし、同タイムは同順位。詳細は `CLAUDE.md` を参照。

## 5. データ管理・バックアップ
- データはブラウザ内に自動保存されるが、ブラウザの履歴・サイトデータを消すと失われる。
- 大会の前後には必ず「データ管理 → バックアップを書き出す」でJSONファイルを保存すること。
- 別のPCに移すときは、フォルダごとコピーしてからバックアップ（.json）を読み込む。
