# ゴール計測器（光電センサ＋GPS時刻＋7セグLED×3）

ゴールラインでライダーの通過時刻を記録するための専用ハードウェア。光電センサで通過を検知し、
GPSモジュールから取得した時刻を3台の8桁7セグメントLED表示器に表示する。ネットワークやPCには
一切接続せず、ゴールオフィシャルが表示とBIBナンバー（目視）を読んで、レース計時集計ツール
（../../index.html）の「③タイム入力」に手入力する運用を前提にしている。

**配線図・部品表（図解）**：https://claude.ai/artifact/1pY9i7K1Std26eMvG4SihK

## 表示する内容

3台の8桁7セグメントLED表示器に、それぞれ以下を表示し続ける。

| 表示器 | 内容 |
|---|---|
| ① 最新通過時刻 | 直近にセンサーが検知した時刻 |
| ② ひとつ前の通過時刻 | その1つ前にセンサーが検知した時刻（入力し忘れの確認用） |
| ③ 現在時刻 | GPSで同期した、常時更新される時計 |

表示形式は8桁の数字 `HHMMSSff`（6桁目の右に小数点灯）。例えば10時05分23.45秒なら
`10052345` と表示され、小数点を含めて読むと `100523.45` になる。これは集計ツールの
タイム入力欄がそのまま受け付ける形式なので、**表示されている数字を見たまま入力すればよい**。

GPS測位状態を示すLEDは緑・赤の2つ。

| 状態 | 緑LED | 赤LED |
|---|---|---|
| 受信良好 | 点灯 | 消灯 |
| 探索中（一度も時刻同期できていない） | 消灯 | 点滅 |
| 同期済みだが現在は精度低下・受信不良 | 消灯 | 点灯 |

赤LED（点滅・点灯いずれか）が出ている間に通過検知があっても時刻を記録できない。緑LEDの点灯を
確認してから計測を始める。

## 配線（ピン対応）

| Arduinoピン | 接続先 | 備考 |
|---|---|---|
| D2 | 光電センサ OUT | 割り込み入力。NPN想定（検知でLOW、`INPUT_PULLUP`）。PNPならコードの変更が必要 |
| D3 | （未使用） | 将来、GPSのPPS信号を使った高精度化をする場合に予約 |
| D4 | GPS状態LED（緑・+抵抗） | 受信良好で点灯 |
| D5 | GPSモジュール TX | ソフトウェアシリアル受信、9600bps |
| D6 | GPSモジュール RX | ソフトウェアシリアル送信。受信のみでよければ未配線でも可 |
| D7 | 表示器チェーン DIN | 3台を数珠つなぎ（DOUT→次のDIN）にして共通配線 |
| D8 | 表示器チェーン CLK | 3台共通配線 |
| D9 | 表示器チェーン CS/LOAD | 3台共通配線 |
| D10 | GPS状態LED（赤・+抵抗） | 探索中は点滅、同期済みだが精度低下中は点灯 |
| 5V / GND | センサー・GPS・表示器3台・LED2個 | 表示器の輝度次第で電流が増えるため、不安定ならUSB以外の5V電源も検討 |

表示器のdevice番号（`goal_timer.ino` 内の `DISP_LATEST`/`DISP_PREV`/`DISP_CLOCK`）は、
Arduinoに一番近い表示器から 0, 1, 2 の順。

## 必要ライブラリ

Arduino IDEの「ライブラリマネージャ」、または `arduino-cli lib install` で以下を入れる。

- **TinyGPSPlus**（Mikal Hart）— GPSのNMEA文を解析する
- **LedControl**（Eberhard Fahle）— MAX7219駆動の7セグ表示器を3台まとめて制御する

## ビルド・書き込み

Arduino IDEを使う場合：
1. `goal_timer.ino` を開く（このフォルダごと `goal_timer` という名前になっている必要がある）。
2. 上記ライブラリをインストール。
3. ボード設定で「Arduino Nano」または「Uno」を選択（Nanoは書き込み時にプロセッサの種類
   （Old Bootloader / ATmega328P）を間違えると書き込めないことがあるので要確認）。
4. 書き込み。

`arduino-cli` を使う場合：
```
arduino-cli compile --fqbn arduino:avr:nano:cpu=atmega328old .
arduino-cli upload -p <シリアルポート> --fqbn arduino:avr:nano:cpu=atmega328old .
```
（Unoの場合は `arduino:avr:uno`。新しいブートローダーのNanoなら `cpu=atmega328old` を外す）

## 調整できる定数（goal_timer.ino 冒頭）

| 定数 | 内容 | 初期値 |
|---|---|---|
| `DEBOUNCE_MS` | センサーの誤multiple検知を防ぐ最短間隔 | 300ms |
| `GPS_STALE_MS` | これより古いGPS時刻情報は同期に使わない | 2000ms |
| `DISP_BRIGHT` | 表示の明るさ（0〜15） | 8 |
| `HDOP_OK` | GPS測位を「良好」とみなすHDOPのしきい値 | 5.0 |

## 設置・運用メモ

- GPSモジュールは屋外の見晴らしの良い場所に設置する（測位に数十秒〜数分かかることがある）。
- 表示器（赤色LED）は直射日光下だと見づらいことがあるので、庇（サンシェード）の設置を推奨。
- この機器はPC・ネットワークには接続しない。記録はゴールオフィシャルの目視・手入力でのみ
  集計ツールに反映される。
- 今後、GPSのPPS（1秒パルス）出力を使うと、NMEA解析の遅延に左右されないより高精度な同期が
  可能になる（現状は未実装。手入力運用には現状の精度で十分）。
