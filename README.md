# MTBエンデューロ タイム集計ツール

インストール不要。`index.html` をダブルクリックすると、ブラウザ（Chrome / Edge 推奨）で起動します。インターネット接続も不要です。

## 使い方
1. **① ライダー登録**
   - 「参加クラス設定」で、その大会の参加クラス（例：IA、IB、ビギナー…）を先に登録します。クラスはイベントごとに変えられます。
   - クラスには任意で「BIB先頭の数字（1〜9）」を設定できます。設定すると、BIBナンバー（3桁・100〜999）の100の位でクラスが分かるようになり（例：IA＝1→101〜199）、ライダー登録時にそのクラスの番号帯から未使用の最小番号が自動入力されます。
   - BIBナンバー（3桁必須。下2桁が00の番号は使用しません）、氏名、読み仮名、参加クラス（上で登録した中から選択）、ICタグID（任意・将来のRFID用）、特記事項を登録します。
2. **② スタートリスト**：登録したライダーから出走順の一覧を作ります。基本は「クラスの出走順→各クラス内はBIBの小さい順」。「クラスの出走順」は▲▼でクラス単位に設定・変更でき（①の参加クラス設定の表示順とは別管理）、個々のライダーも一覧の▲▼で手動並べ替えできます。ライダーの登録・削除に合わせて一覧も自動で更新されます。印刷・PDF保存にも対応しています。
3. **③ タイム入力**：BIB、セクション#、スタート時刻、ゴール時刻、状態を入力します（出走・計測の記録）。
   - 時刻は `10:05:23.45` と `100523.45` のどちらの形式でも入力できます（全角も可）。
   - Enterキーで次の欄へ移り、最後の欄でEnterを押すと登録されます。
   - スタート時刻とゴール時刻は、別々に入力してもかまいません（都度のリザルト入力に対応）。
4. **④ 結果・順位**：総合順位とクラス別順位を表示します。印刷やPDF保存、CSV保存ができます。

詳しい操作手順は `docs/manual.md`（操作マニュアル）にまとめています。

## データの保存について
- 入力したデータはブラウザ内に自動保存されます。**ただし、ブラウザの履歴やサイトデータを消すと、データも消えます。**
- 大会の前後には、必ず「データ管理 → バックアップを書き出す」を実行してください。
- 別のPCへ移すときは、フォルダごとコピーしてから、バックアップファイル（.json）を読み込みます。

